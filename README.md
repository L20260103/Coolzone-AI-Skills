# Coolzone AI Skills

Agent skills for Coolzone (czair.com.au), shared by Jack, Lawrence, and Ping. Templates and the handover document are intentionally not included in this public repository. Signature images live in `skills/coolzone-certificate/signatures/` locally and are intentionally not committed.

Coolzone（czair.com.au）助理技能，由 Jack、Lawrence、Ping 共用。模板和交接文档有意不包含在这个公开仓库中。签名图片放在本地的 `skills/coolzone-certificate/signatures/`，有意不提交。

## Skills / 技能

| Skill | Description / 说明 |
| --- | --- |
| [coolzone-common-rules](skills/coolzone-common-rules/SKILL.md) | Use before any Coolzone (czair.com.au) work for Jack, Lawrence or Ping: who is using it, company details, signatures, site contact list, iron rules, and where the source files live. 在为 Jack、Lawrence 或 Ping 做任何 Coolzone（czair.com.au）工作之前使用：确认当前使用者、公司资料、签名、现场联系人名单、铁律，以及源文件所在位置。 |
| [coolzone-purchasing](skills/coolzone-purchasing/SKILL.md) | Use when someone at Coolzone (Jack, Lawrence or Ping) wants to order materials, create a delivery PO, order grilles (bar grille / linear slot / WPL), order duct materials from PolyPlan, or update PO / Grille logs. 当 Coolzone 的 Jack、Lawrence 或 Ping 要订材料、建送货 PO、订格栅（bar grille / linear slot / WPL）、从 PolyPlan 订风管材料，或更新 PO / Grille 记录时使用。 |
| [coolzone-rfq-quotes](skills/coolzone-rfq-quotes/SKILL.md) | Use when someone at Coolzone (Jack, Lawrence or Ping) wants to request manufacturer quotes (RFQ) for a project, check or update the Tender log and due dates, or file supplier quotes that came back. 当 Coolzone 的 Jack、Lawrence 或 Ping 要为项目向厂家询价（RFQ）、查看或更新 Tender log 和截止日期，或归档已返回的供应商报价时使用。 |
| [coolzone-job-profit](skills/coolzone-job-profit/SKILL.md) | Use when someone at Coolzone (Jack, Lawrence or Ping) names a JB job or site and asks about profit, cost, margin, or 利润/成本/毛利. 当 Coolzone 的 Jack、Lawrence 或 Ping 点名某个 JB 工单或工地，并询问 profit、cost、margin，或利润/成本/毛利时使用。 |
| [coolzone-certificate](skills/coolzone-certificate/SKILL.md) | Use when someone at Coolzone (Jack, Lawrence or Ping) asks for a certificate / cert / 证书 for a JB job, or a declaration letter for a building surveyor. 当 Coolzone 的 Jack、Lawrence 或 Ping 要求为某个 JB 工单出具 certificate / cert / 证书，或写给 building surveyor 的声明信（declaration letter）时使用。 |
