# Coolzone-Jack

Agent skills for Coolzone (czair.com.au). Templates, the signature image, and the handover document are intentionally not included in this public repository.

Coolzone（czair.com.au）助理技能。模板、签名图片和交接文档有意不包含在这个公开仓库中。

## Skills / 技能

| Skill | Description / 说明 |
| --- | --- |
| [coolzone-common-rules](skills/coolzone-common-rules/SKILL.md) | Use before any Coolzone (czair.com.au) work for Lawrence: company details, signature, site contact list, iron rules, and where the source files live. 在为 Lawrence 做任何 Coolzone（czair.com.au）工作之前使用：公司资料、签名、现场联系人名单、铁律，以及源文件所在位置。 |
| [coolzone-purchasing](skills/coolzone-purchasing/SKILL.md) | Use when Lawrence wants to order materials, create a delivery PO, order grilles (bar grille / linear slot / WPL), order duct materials from PolyPlan, or update PO / Grille logs. 当 Lawrence 要订材料、建送货 PO、订格栅（bar grille / linear slot / WPL）、从 PolyPlan 订风管材料，或更新 PO / Grille 记录时使用。 |
| [coolzone-rfq-quotes](skills/coolzone-rfq-quotes/SKILL.md) | Use when Lawrence wants to request manufacturer quotes (RFQ) for a project, check or update the Tender log and due dates, or file supplier quotes that came back. 当 Lawrence 要为项目向厂家询价（RFQ）、查看或更新 Tender log 和截止日期，或归档已返回的供应商报价时使用。 |
| [coolzone-job-profit](skills/coolzone-job-profit/SKILL.md) | Use when Lawrence names a JB job or site and asks about profit, cost, margin, or 利润/成本/毛利. 当 Lawrence 点名某个 JB 工单或工地，并询问 profit、cost、margin，或利润/成本/毛利时使用。 |
| [coolzone-certificate](skills/coolzone-certificate/SKILL.md) | Use when Lawrence asks for a certificate / cert / 证书 for a JB job, or a declaration letter for a building surveyor. 当 Lawrence 要求为某个 JB 工单出具 certificate / cert / 证书，或写给 building surveyor 的声明信（declaration letter）时使用。 |
